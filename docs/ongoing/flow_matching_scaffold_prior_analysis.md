## 1. 핵심 문제 진단: 왜 Zero Plant Array ($x_0 = \mathbf{0}$)에서 한계가 발생하는가?

### 1.1 위상 공간의 특이점(Singularity)과 모드 붕괴(Mode Collapse)
- **점 특이점 집약**: $x_0 = \mathbf{0}$에서는 $N$개의 모든 슬롯이 정확히 $(0, 0, 0)$이라는 단 하나의 점에 완전히 중첩되어 시작합니다.
- **구배 충돌(Gradient Competition)**: Flow Matching의 속도장 $v_\theta(x_t, t, I)$ 관점에서, $t=0$일 때 모든 슬롯의 쿼리 상태가 동일하므로 트랜스포머의 Self-Attention이 슬롯들을 3D 캐노피의 각기 다른 위치로 분산시키는 과정에서 극심한 구배 충돌이 발생합니다.
- **평균화 병목(Averaging Bottleneck)**:
  - **DAP 10 (유묘)**: 작은 잎들이 과도하게 팽창하여 캔버스를 가득 채움.
  - **DAP 50/90 (성숙 식물)**: 슬롯들이 중심에서 밖으로 충분히 뻗어나가지 못하고 중심부 평균 위치로 뭉침.

### 1.2 Optimal Transport Flow Matching (OT-CFM) 수학적 원리 위배
- Flow Matching(Rectified Flow)의 수학적 이론(Lipman et al., 2023)은 **공간에 고르게 퍼져 있는 Prior 분포 $p_0(x)$**로부터 **목표 데이터 분포 $p_1(x)$**로의 최적 수송(Optimal Transport) 직선 경로를 학습하는 것입니다.
- 출발점 $x_0$가 3D 공간에 미리 분산되어 있어야 경로 간 교차(Trajectory Crossing)가 최소화되고, 각 슬롯이 가장 가까운 잎/줄기 목적지로 최소 거리 직선 이동을 수행할 수 있습니다.

## 3. Uniform Botanical Scaffold Prior ($x_0 \sim p_{\text{scaffold}}$) 아키텍처

사용자 제안에 따라 $x_0$를 순수 0이 아닌 **실측 통계 비율과 3D 식물 기하 구조를 반영한 Uniform Botanical Scaffold**로 초기화합니다.

```
[기존 방식: Zero Init]
x0 = (0, 0, 0) 단일 점  --->  모든 슬롯이 중심에서 출발하여 방사상 팽창 (경로 교차 & 왜곡)

[개선 방식: Uniform Botanical Scaffold Prior]
x0 = 3D 캐노피 원기둥/원추형 볼륨에 2,048개 슬롯을 피보나치 나선 및 해부학적 비율로 균일 배치
   --->  모델은 2D 입력 이미지를 보며 '존재하는 영역'의 기관만 정밀 정렬하고, '비어 있는 영역'은 p(empty) -> 1.0으로 소멸
```

### 3.1 3D 공간 기하학적 배치 규칙
1. **Stem / Internode (14%)**:
   - $z$축 중심 원기둥($r \le 0.05\text{m}, z \in [0.0, 0.7]\text{m}$)을 따라 수직 직립 배열.
2. **Petiole / Peduncle (27%)**:
   - 중심 줄기에서 외곽으로 $30^\circ \sim 60^\circ$ 각도로 방사형 분기.
3. **Leaf (40%)**:
   - 엽병 끝부분 및 캐노피 외곽 볼륨($r \in [0.08, 0.45]\text{m}, z \in [0.05, 0.65]\text{m}$)에 피보나치 황금각($\theta = 137.5^\circ$) 나선 배치.
4. **Bud / Flower / Fruit (18%)**:
   - 줄기 마디의 엽액(Axil) 및 분기점에 고르게 분포.

### 3.2 기대 효과
1. **DAP 10 유묘**:
   - 중심부의 어린 잎 슬롯들만 미세 정렬되고, 바깥쪽 잉여 슬롯들은 $p(\text{empty}) \rightarrow 1.0$으로 깨끗이 소멸되어 **작고 날카로운 유묘 잎** 복원.
2. **DAP 50/90 성숙 식물**:
   - 이미 3D 캐노피 전역에 슬롯들이 균일하게 퍼져 있으므로, 모델이 멀리 있는 잎을 무리하게 밀어낼 필요 없이 **제자리에서 즉시 풍성한 대형 캐노피를 형성**.
3. **학습 수렴 가속 및 충실도 극대화**:
   - 이동 거리($\|x_1 - x_0\|$)가 대폭 단축되어 Flow Matching 직선 경로가 단순해지고 Transformer의 속도장 예측 정확도가 극대화됨.
