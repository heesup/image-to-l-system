# dataset/

**Data only** — this directory holds generated datasets and caches. All dataset *code* lives in
`plant_recon/dataset/` (or, for the archived tracks, in `archive/`).

## Layout

| Path | Contents | Status |
| :--- | :--- | :--- |
| `helios_data/cowpea/` | 100,000 Helios XML plant definitions (100 seeds × 100 DAPs) + `*.jpeg` raytraced renders | gitignored, generated by `scripts/generate_helios_dataset.py` (via `scripts/generate_helios_dataset_jobs.sh`) |
| `helios_data/bean/`, `helios_data/sorghum/` | Other-species XMLs | gitignored |
| `cache/cowpea_curv26/` | Per-plant `.pt` cache: 16-channel image pyramid + GT nodes/phytomer ids | gitignored, generated by `plant_recon/dataset/generate_cache.py` |
| `cache/cowpea_curv26_pkt/` | Phytomer packet cache (pkt_version 6, bottom-to-top) | gitignored |
| `cache/cowpea_curv26_pkt_v9/` | Phytomer packet cache (pkt_version 7, terminal-last) — pairs with `PHYTOMER_TERMINAL_LAST=1` | gitignored |
| `cache/cowpea_curv26_subset4k/` | 4,000-file symlink subset for fast smoke tests | gitignored |

## Conventions

- The packet caches are **VAE-independent** since 2026-09-14: FM encodes Stage-3 target latents on
  the fly. Only the packet *order* must match the VAE (`pkt_version` / `PHYTOMER_TERMINAL_LAST`).
- Regenerate via `scripts/generate_helios_dataset_jobs.sh` (`--packets-only`, `--pkt-version`,
  `--terminal-last`); never edit cache files in place.
